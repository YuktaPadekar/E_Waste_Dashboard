## 📌 Executive Summary

This interactive academic web dashboard serves as the comprehensive, faculty-ready portfolio presenting all assignments, empirical datasets, statutory compliance models, technical posters, slide decks, and research papers developed by **Yukta Padekar**.

The central focus of this portfolio investigates **sub-national electronic waste (e-waste) management in ecologically fragile mountain ecosystems**, taking **Sikkim, India** as a principal case study under the statutory framework of the **E-Waste (Management) Rules, 2022**.

## 🛠️ Technology Stack & Architecture

- **Frontend Core**: React 19, TypeScript, Vite 8
- **Styling & Design System**: Tailwind CSS v4, Custom Emerald/Forest Green Theme (`#143D2B`, `#059669`, `#F8FAF8`), Full Dark Mode support
- **Data Visualizations**: Recharts (Responsive bar charts, dual-axis compositions, doughnut breakdowns, and capacity utilization bars)
- **Icons & Assets**: Lucide React
- **Document Previews**: High-resolution PyMuPDF-rendered PNGs for zero-latency, multi-page document inspection
- **Spreadsheet Engine**: Interactive 8-sheet client viewer with search and row filtering

## 🚀 Running Locally

### Prerequisites
- Node.js 18+ (tested on Node v24.14.1)
- npm 9+

### Installation & Execution
```bash
# Clone or navigate to the repository
cd Dasboard

# Install dependencies
npm install

# Start development server
npm run dev

# Open in browser at:
# http://127.0.0.1:5173/
```

### Production Build
```bash
# Compile TypeScript and bundle assets
npm run build

# Preview production build locally
npm run preview
```
